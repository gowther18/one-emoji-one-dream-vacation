# One Emoji, One Dream Vacation

[![make.fun · u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35](https://make.fun/badge/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35.svg)](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35)

One emoji, nothing else — the dream vacation in a single glyph:

> ⛩️

A vermilion torii gate: Japan in one character. It is a specific,
walkable place, not a generic holiday — a threshold you step through
into a shrine, a forest, a whole trip — while the field is crowded
with desert islands (🏝️), Mount Fuji (🗻) and sunrises over the sea
(🌅). It reads instantly at any size, on any screen, in any culture.

## Run it

```sh
python3 main.py
```

Writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), byte-identical on every run, no trailing
newline. Python 3.13, standard library only, no network.
